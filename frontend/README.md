# Personal Job Finder — Frontend

React + TypeScript + Vite dashboard for the local Personal Job Finder application.

Run the backend first, then:

```bash
npm install
npm run dev
```

The app runs at <http://127.0.0.1:5173> and proxies `/api` to
`http://127.0.0.1:8000`.

See the repository root `README.md` for the full setup and the architecture overview.
