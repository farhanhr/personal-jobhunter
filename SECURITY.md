# Security Policy

## Supported scope

This project is a personal local-first application. Security reports should focus on vulnerabilities in application code, credential handling, data exposure, unsafe connector behavior, or dependency vulnerabilities.

## Reporting

Please use GitHub's private vulnerability reporting / Security Advisories feature when it is enabled for this repository. Do not create a public issue containing credentials, personal data, OAuth tokens, or exploit details that expose a user.

## Sensitive data

Never attach a real CV, Gmail message, LinkedIn session, Google OAuth credential, spreadsheet export, recruiter contact list, or local database to an issue or pull request.

## Response expectations

This is a personal project and no formal response-time SLA is promised. Reports will be reviewed on a best-effort basis.
