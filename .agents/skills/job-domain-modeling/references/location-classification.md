# Location Classification

Retain the original text and store normalized fields separately.

Suggested classifications:

- `INDONESIA_ONSITE_OR_HYBRID`
- `REMOTE_INDONESIA_ELIGIBLE`
- `REMOTE_WORLDWIDE`
- `OUTSIDE_INDONESIA`
- `UNKNOWN_REVIEW`

Do not infer remote eligibility from `Remote` alone. A recruiter/post author's location is not a job location. Unknown values should remain unknown until evidence is available.
