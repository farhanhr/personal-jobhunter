# Architecture Decision Records

This directory is the canonical home for new and amended ADRs.

- `docs/p0/07-architecture-decision-records.md` is the original P0 0.1 decision baseline.
- `ADR-013` through `ADR-019` are the accepted P0.1 amendments (owner-approved 2026-11-13).
- New ADRs start as `Proposed` and become `Accepted` only after the owner approves them. Do not treat a draft as silently accepted.

Use this template for future decisions:

1. Status (`Proposed`, `Accepted`, `Superseded`, `Rejected`).
2. Context and constraints.
3. Options considered (at least two for consequential choices).
4. Decision.
5. Consequences/trade-offs.
6. Tests/verification required.
7. Related ADRs and documents.
